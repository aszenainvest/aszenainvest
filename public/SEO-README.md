# SEO Optimization Guide for Aszena Invest

## Open Graph Image Requirements

To complete the SEO setup, you need to create an Open Graph image:

### Image Specifications:
- **Filename**: `og-image.jpg`
- **Location**: `/public/og-image.jpg`
- **Dimensions**: 1200 x 630 pixels (recommended)
- **Format**: JPG or PNG
- **File Size**: Under 1MB for optimal loading

### Design Recommendations:
1. **Include**:
   - Aszena Invest logo
   - Budapest skyline or iconic building (e.g., Parliament)
   - Company slogan: "Trust - Vision - Growth"
   - Website URL: www.aszenainvest.hu

2. **Colors**: 
   - Primary: #24248A (dark blue)
   - Accent colors from brand palette
   - High contrast for readability

3. **Text**:
   - Keep text large and readable
   - Avoid small fonts (minimum 60px for headlines)
   - Safe zone: Keep important content 40px from edges
